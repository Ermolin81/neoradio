# ⚡ NeoRadio - Modern Portable Audio Streamer

Ультра-легковесный портативный интернет-радиоплеер с современным интерфейсом (Glassmorphism / OLED Dark) на системном движке Microsoft Edge WebView2.

---

## 🚀 Быстрый запуск
* Запустите файл **`NeoRadio.exe`** прямо из папки `P:\online_radio\`
* Вес исполняемого файла: всего **~10.7 МБ** (в 4 раза легче старых сборок).
* Работает на любой Windows 10/11 без установки Python и сторонних кодеков.

---

## 🎨 Особенности интерфейса
1. **Glassmorphism & OLED Dark:** современный полупрозрачный дизайн с неоновыми акцентами, мягкими тенями и стильной типографикой.
2. **Живой визуализатор:** анимированные волны эквалайзера, реагирующие на статус воспроизведения в реальном времени.
3. **Карточки станций:** быстрое переключение радиостанций в один клик.
4. **Управление громкостью:** плавный слайдер с цифровым индикатором и кнопкой быстрого отключения звука (Mute).
5. **Добавление своих станций:** кнопка **«+ Добавить»** с аккуратным всплывающим окном и сохранением в `stations.json`.

---

## 📻 Предустановленные станции
* ⚡ **Radio Rock Suomi** — адаптивный HLS HD-поток (256 kbps).
* 🎸 **Radio City (Finland)** — легендарный финский рок-эфир через официальный поток Rayo.
* 🔥 **Radio SuomiRock** — финский рок от Bauer Media.
* 🌆 **Synthwave Radio** — ретро-вейв и киберпанк 24/7 (320 kbps).
